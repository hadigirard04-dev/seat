# seat UI 三版设计调研

对照产品（真实锚点，不是「随便好看」）：

| 版本 | 风格锚点 | 色 | 字 | 密度 | 给人的感觉 |
|---|---|---|---|---|---|
| **V1 Ink 编辑部** | 瑞士海报 + Stripe 通讯稿 + 纸质周报 | 米纸底、墨黑、朱砂一点 | 大衬线标题 + 无衬线正文 | 中高，强调信息层级 | 严肃、能进作品集、像「发布物」 |
| **V2 Console 控制台** | Linear / Raycast / 终端 HUD | 近黑面板、单线描边、电光青 | 等宽数字/标签 + 系统无衬线 | 高密度、键盘感 | 工程师、高效、专业工具 |
| **V3 Bloom 柔和** | Things 3 / Arc / Notion 日常 | 暖灰、大圆角、靛蓝一点 | 几何无衬线、大字号下一步 | 低密度、大留白 | 亲切、想每天打开、产品感 |

## 问题诊断（为什么现在丑）

1. 四张同级卡片均重，没有视觉焦点（「下一步」不够「下一步」）
2. 深色但无层次：只有描边，没有深度/纸感/网格
3. 字号梯度不够，中文排版未做「一眼扫读」
4. 强调色蓝很工具默认，缺乏记忆点
5. 进度条/徽章像 Bootstrap 默认件

## 三版原则

- **同一套信息架构**：当前项目 → 下一步 → DoD → 指令坞，交互一致，只换视觉系统
- **各自有一条签名记忆点**：V1 红色索引线+衬线巨标；V2 快捷键 chip + 等宽计数；V3 巨大下一步卡片 + 软阴影
- **可截图、可并排对比**
